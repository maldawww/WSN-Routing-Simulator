# WSN Routing Simulator

Aplikacja WPF do symulacji protokołów routingu w sieciach sensorowych.

## Funkcje:
- Symulacja krokowa i automatyczna
- Dwa protokoły: Shortest Path i Minimum Energy
- Symulacja awarii i zgubionych pakietów
- Eksport wyników i wizualizacja danych
